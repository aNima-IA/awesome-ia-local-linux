# Assets

Carpeta reservada para recursos gráficos del repositorio (logo, banner de la cabecera del README, diagramas de arquitectura).

Convenciones acordadas:

- Formatos preferentes: SVG para logotipos y esquemas; PNG optimizado o WebP para imágenes rasterizadas.
- Nombres en `kebab-case`, con sufijo de variante cuando exista (por ejemplo, `logo-light.svg`, `logo-dark.svg`).
- El README no dependerá de assets remotos: todo lo que se muestre vivirá aquí para que el repositorio sea autosuficiente.
- Aún no hay arte final generado; la cabecera del README funciona sin imágenes.
