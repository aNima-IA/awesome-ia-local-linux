# Soporte

## Dudas sobre el contenido del listado

- Si un enlace no funciona o apunta a algo distinto de lo descrito, abre un issue con la plantilla **«Enlace roto»** (`.github/ISSUE_TEMPLATE/report-broken-link.yml`).
- Si quieres proponer un recurso nuevo, usa la plantilla **«Añadir recurso»** (`.github/ISSUE_TEMPLATE/add-resource.yml`). El proceso completo está en [CONTRIBUTING.md](CONTRIBUTING.md).
- Para mejoras generales (nuevas categorías, estructura, documentación), abre un issue describiendo la propuesta y su motivación.

## Preguntas sobre las herramientas enlazadas

**Este repositorio no da soporte técnico de las herramientas listadas.** Cada proyecto tiene sus canales oficiales:

- Consulta primero la documentación oficial enlazada en cada entrada del README.
- Para problemas de instalación o uso, usa el tracker de issues del propio proyecto o su comunidad (Discord, Matrix, foro…).
- Las preguntas de soporte de terceros abiertas aquí se cerrarán con un enlace al canal correcto.

## Preguntas sobre hardware y compatibilidad

Las notas de compatibilidad del README (`[NVIDIA CUDA]`, `[AMD ROCm]`, `[Vulkan]`, `[CPU]`…) son indicativas y provienen de la documentación oficial de cada proyecto. Para requisitos concretos (VRAM, drivers, versiones), consulta siempre la documentación del proyecto; si detectas que una nota es incorrecta o está desactualizada, repórtala como «Enlace roto» o propón la corrección en un PR.

## Tiempos de respuesta

Este es un proyecto mantenido en tiempo libre. Los issues se revisan con regularidad; los reportes de enlaces rotos y de seguridad tienen prioridad.

## Vulnerabilidades

Si lo tuyo es un problema de seguridad (por ejemplo, un enlace malicioso o un proyecto comprometido), no abras un issue público: sigue las instrucciones de [SECURITY.md](SECURITY.md).
